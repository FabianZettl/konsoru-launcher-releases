## KONSORU Launcher v0.1.0 — first public feedback build

This is the first public release of KONSORU, a native Android HOME-replacement launcher for the
AYN Thor with a bespoke themed UI per emulated console (Switch, GameCube, Wii, Wii U, 3DS, PS2,
PSP, SNES/Classic-Mini, Dreamcast — everything else uses a generic grid for now).

**This is not a finished product.** It's shared specifically to get feedback from real Thor owners
— expect bugs, especially around some emulators not yet booting games correctly. See the README
for the current known issues.

### Install

1. Download `KONSORU-Launcher-v0.1.0.apk` below
2. Allow installing apps from that source when Android prompts you
3. Install and open — first launch walks you through picking your ROM folder
